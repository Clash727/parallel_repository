# parallel_repository

This repository stores the experiment materials selected from the local Lab1 workspace.

## Structure

- `source/`: experiment source code
- `raw_data/`: raw or organized experiment data files
- `data_processing/`: scripts used to process data

## Sources

- `source/exp1/lab1-exp1.cpp` comes from `lab1-exp1/lab1-exp1/lab1-exp1.cpp`
- `source/exp2/lab1-exp2.cpp` comes from `lab1-exp2/lab1-exp2/lab1-exp2.cpp`
- `raw_data/` comes from `report/data/`
- `data_processing/generate_figures.py` comes from `report/scripts/generate_figures.py`
